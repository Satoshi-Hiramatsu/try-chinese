## 手順

### 1. 表情シートを生成する（1体あたり約 $0.245）

```bash
export OPENROUTER_API_KEY=sk-or-v1-...
node scripts/generate-portrait-sheet.mjs --id pt-nuan --out tmp/sheet-nuan.png
```

元イラスト `web/public/portraits/<id>.jpg` を参照として渡し、5列×2行＝10コマの
グリーンバックのシート（5504×3072）を生成します。

### 2. 10枚の透過立ち絵へ切り分ける

```bash
node scripts/sheet-to-portraits.mjs --id pt-nuan \
  --sheet tmp/sheet-nuan.png \
  --ref web/public/portraits/pt-shixun-neutral.webp \
  --contact tmp/contact-nuan.png
```

`--ref` は「頭の大きさ・位置を合わせる基準」です。完成済みの立ち絵を渡せば、
既存キャラと同じ枠に揃います。`--contact` で出力した確認用シート（透明部分がマゼンタ）を
必ず目視し、髪の周りに背景が残っていないか、10コマで顔が動いていないかを確認します。

### 3. 解放する

`web/src/data/portraits.ts` の `PORTRAIT_EXPRESSION_IDS` に ID を追加します。
追加を忘れると「表情差分の画像が揃っている立ち絵は、すべて有効になっている」テストが落ちます。

### 4. 確認

```bash
npm run build && npm test
npm run dev:web   # http://localhost:5173/preview.html?view=expressions
```

## 落とし穴

- **4K が出せるのは `-preview` 系のモデルだけ。** 無印 `google/gemini-3-pro-image` に
  `image_config.image_size: '4K'` を渡すと 400 が返ります。
- **応答の `images` は2枚。** 低解像度プレビュー（1376×768）と本命（5504×3072）が入るので、
  必ず**最後の1枚**を使います。1376×768 では1コマ 275px しか取れず、立ち絵として使えません。
- **コマの構図はプロンプトで制御できません。** 「もっと引いて腰まで」と強く指示すると、
  むしろ寄った上に頭頂が切れます。生成結果を受け入れ、`sheet-to-portraits.mjs` の
  頭サイズ正規化に任せるのが確実です。
- **OpenRouter のキーには月間上限があります。** 会話・TTS と同じキーを使うため、
  生成で使い切るとアプリ側が止まります。残高は `GET https://openrouter.ai/api/v1/key` で確認できます。
- **API キーは絶対にコミットしないこと。** スクリプトは環境変数 `OPENROUTER_API_KEY` からのみ読みます。
