# 日中混合読み上げ音声の保留案

## ステータス

- **状態**: 保留（未実装）
- **記録日**: 2026-09-09
- **再検討時期**: 日中混合読み上げの優先度が上がったとき
- **現在の挙動**: Kokoro 82M を含む既存 TTS で、中国語本文（`reply.zh`）のみを読み上げる

この文書は将来の実装候補を残すための設計メモであり、現行機能や確定仕様を表すものではない。

## 目的

「你好 は日本語で『こんにちは』という意味だよ」のような日本語・中国語混在文を、それぞれの言語として自然に発音しながら、キャラクターごとの声の印象をできるだけ維持する。

## 前提

- メイン TTS は `hexgrad/kokoro-82m` とする。
- 現在の中国語8話者と、友達ごとの速度・ピッチ・音量設定を尊重する。
- API キーと設定は引き続きブラウザ側に保持し、Worker は転送と検証に徹する。
- 既存の中国語のみの読み上げ、停止、キャッシュ、ハンズフリー再開を壊さない。

## 既知の制約

Kokoro 82M のプリセット音声は言語別で、中国語は女性4・男性4、日本語は女性4・男性1である。中国語話者 `zf_*` / `zm_*` と日本語話者 `jf_*` / `jm_*` は別の声であり、プリセットだけで声紋レベルの同一性は保証できない。

特に男性の日本語話者が1つしかないため、20人全員に固有の日本語声を割り当てることはできない。実装する場合の目標は「完全に同じ声」ではなく、性別・年齢感・高さ・速度・話し方を合わせて同一人物らしく聞かせることとする。

また、Kokoro の音声仕様では短すぎる発話で品質が低下する可能性が示されている。中国語単語だけを細かく分割せず、自然な区切りでまとめる必要がある。

参考:

- [Kokoro 82M の音声一覧](https://huggingface.co/Codobo/Kokoro-82M/blob/main/VOICES.md)
- [OpenRouter の Kokoro 82M](https://openrouter.ai/hexgrad/kokoro-82m/providers)

## 保留中の実装案

### 1. 言語区間を構造化する

文字種だけでは漢字が日本語か中国語か判定できないため、LLM の応答へ任意の読み上げ区間を追加する。

```ts
interface SpeechSegment {
  language: 'zh-CN' | 'ja-JP'
  text: string
}
```

```json
{
  "speechSegments": [
    { "language": "zh-CN", "text": "你好" },
    { "language": "ja-JP", "text": "は、日本語で「こんにちは」という意味だよ。" }
  ]
}
```

`speechSegments` がない既存応答では、従来どおり `reply.zh` を読み上げる。

### 2. キャラクターごとに日中話者をペアリングする

`Voice` に後方互換のある言語別話者設定を追加する案とする。

```ts
voiceModelByLanguage?: {
  zh: string
  ja: string
}
```

中国語声と日本語声を、性別・声の高さ・年齢感・明るさを基準に試聴してペアリングする。速度とピッチは両言語で共通設定を使う。

### 3. Worker の話者検証を言語別にする

現在は Kokoro の中国語話者だけを許可しているため、日本語話者を追加する。

- `zh-CN`: `zf_*` / `zm_*`
- `ja-JP`: `jf_*` / `jm_*`

言語と話者が一致しないリクエストは、安全な既定話者へフォールバックする。

### 4. 音声を先行生成して連続再生する

すべての区間を先に取得してから順番に再生し、通信待ちによる不自然な無音を防ぐ。言語境界には短い自然な間を置く。

- 再生開始・終了通知は全文で一度だけ発火
- 停止時はキューと遅延レスポンスをすべて無効化
- キャッシュキーに言語・話者・速度・本文を含める
- ハンズフリーのマイク再開は全文の終了後に一度だけ実行

## 実装を再開する場合の順序

1. 日本語5話者と中国語8話者で混合例文を試聴し、品質評価表を作る。
2. 代表的な男女キャラクターで日中話者ペアを決める。
3. `SpeechSegment` と後方互換処理を追加する。
4. `/api/tts` を日本語話者と `language` に対応させる。
5. 複数音声の先行取得・連続再生・停止処理を実装する。
6. 声質設定画面へ日本語声と混合プレビューを追加する。
7. 自動テスト、実機試聴、README、CHANGELOG を更新する。

## 合格基準

- 「你好」は中国語の声調で、「こんにちは」は日本語として発音される。
- 言語切り替え時に性別や年齢感が大きく変化しない。
- 区間の境界に通信待ち由来の長い無音や音切れがない。
- 中国語のみの既存読み上げ品質が低下しない。
- 停止、キャッシュ、自動読み上げ、ハンズフリーが従来どおり動作する。
- `npm test` と `npm run build` が成功する。

## 再開条件

次の条件がそろった段階で再検討する。

- 日本語を音声でも聞きたいという利用要望が十分にある。
- OpenRouter 上で日本語 Kokoro 話者が安定して利用できる。
- 話者ペアの試聴で、キャラクター性を許容範囲内に維持できる。
- 男性日本語話者が1つしかない制約を、話者共有または別方式で許容できる。

声質の完全一致が必須になった場合は、Kokoro プリセットのペアリングではなく、話者埋め込みやクロスリンガル音声生成を扱える独自推論環境を別案として評価する。
