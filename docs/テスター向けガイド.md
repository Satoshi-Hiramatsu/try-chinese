# しゃべチャイナ テスター向けガイド

テストに参加してくれてありがとうございます。このページだけ読めば始められるように書いています。

- アプリ: https://try-chinese.molkz.com
- 必要なもの: **OpenRouter の API キー**（会話と音声の費用はこのキーから支払われます）、マイク付きのスマホか PC、Chrome / Edge / Safari のいずれか

---

## 1. OpenRouter のキーを用意する（5分）

1. https://openrouter.ai にアクセスし、Google などでサインアップします。
2. 右上のメニュー → **Credits** で **$5** ほどチャージします（カード決済）。1回の会話往復は 1円前後なので、$5 あれば十分に試せます。
3. **Settings → Keys → Create Key** でキーを作ります。名前は何でも構いません。`sk-or-v1-...` で始まる文字列が表示されるのでコピーしておきます（あとから再表示できないので、無くしたら作り直してください）。

キーは誰にも渡さないでください。アプリはキーをあなたのブラウザの中にだけ保存し、サーバーには残しません。

## 2. アプリにキーを入れる

1. アプリを開き、画面をタップしてメニューを出します。
2. **「APIキー」** を押してキーを貼り付け、**「確認」** で「有効」と出るのを見てから **「保存」** します。
3. **「はじめる」** で趣味と HSK 級（迷ったら 1〜2 級）を選び、友達を1人選びます。

キーが無いまま話そうとすると、キー入力の画面が理由つきで開きます。

## 3. 話してみる

- 入力欄に **中国語でも日本語でも片言でも** 書いて送ります。マイクのボタンで話しかけることもできます。
- 返答はピンイン・中国語・日本語訳で出ます。**スピーカーのボタン** で友達の声で読み上げます。設定で「自動で読み上げる」を ON にすると毎回鳴ります。
- 返答の下の「添削アドバイス」を開くと、より自然な言い方が見られます。
- 立ち絵の横の ⚙️ で **声の高さ** だけ変えられます（低め〜高め）。話者そのものは変えられません。

## 4. 費用の目安

| 使い方 | 目安 |
| --- | --- |
| 1往復（送信 → 返答 → 読み上げ1回） | 1円前後（読み上げを繰り返すと増える） |
| 30分ほど話す | $0.1〜0.3 程度（多めに見ても $0.5） |

音声（Fish Audio）は文字数に応じた課金で、会話（DeepSeek V4.1 Flash: 入力 $0.15 / 出力 $0.6 per 100万トークン）より高めです。上の目安は 2026-09 時点の概算で、実測で更新します。読み上げを何度も鳴らすとその分かかります。残高が切れると会話が止まり、キーの状態が「残高切れ」になります。チャージしてからキーの状態バッジで「確認」を押し直してください。

## 5. うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「会話には OpenRouter API キーが必要です」と出る | キーが未入力か、無効・残高切れです。「APIキー」から貼り直して「確認」 |
| 音が鳴らない | 一度画面のどこかをタップしてから再生してください（ブラウザの自動再生制限）。iPhone はマナーモードだと鳴りません |
| 「この友達の声はまだ設定されていません」 | その友達の声が準備中です。別の友達を選んでください（分かれば教えてください） |
| マイクが使えない | ブラウザのマイク許可を確認。Safari は音声認識に対応していない場合があります |
| 返答が明らかにおかしい・止まる | どの友達と、何を送ったかを添えて教えてください |

## 6. フィードバックのお願い

次のことを、気づいたときに送ってください。細かいことほど助かります。

- 声が本人（キャラクター）に合っているか、聞き取りやすいか
- 返答の中国語がレベルに合っているか、添削が納得できるか
- 「ここで止まった」「この画面が分からなかった」
- スマホの機種・ブラウザ名

送り先: 開発者に直接（LINE / メール）でお願いします。
