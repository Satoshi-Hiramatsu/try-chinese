## 1. 目的

友達（一般ユーザー）にテストしてもらえる状態にする。利用者に見せる調整項目を **声の高さ（ピッチ）だけ** に絞り、それ以外の「開発中に比較・検証するための機能」はすべて開発者モード（`#dev`）へ移す。音声は **Fish Audio S2.1 Pro（OpenRouter 経由）専用** とし、Kokoro・Qwen・ブラウザ音声とその設定を取り除く。

| 項目 | 利用者に見える状態 |
| --- | --- |
| API キー | OpenRouter のキーを1つ入力する（必須） |

Fish 専用にした後の `Voice`:

```ts
export interface Voice {
  gender: 'male' | 'female'
  /** Fish Audio の話者ID (reference_id)。必須 */
  voiceModel: string
  rate?: number
  /** 声の高さ。利用者が唯一触れる値。0.85〜1.20 */
  pitch?: number
  voiceTuning?: TtsVoiceTuning
}
```

`ttsModel` はフィールドから外し、`FIXED_TTS_MODEL = 'fish-audio/s2.1-pro'` を定数で持つ（TTS 検証モードは自前で `model` を指定して Worker を叩くので影響なし）。

| --- | --- | --- |

### 2-5. 無料モード（キー無し・無効・残高切れのとき）

T-88〜T-90 で入れた仕組み。LLM は Worker の `:free` モデル、TTS は `fish-audio/s2.1-pro-free:free` に差し替わる。画面の文言（「未設定 · 無料モードで動きます」「キーが無くても無料の音声で話せます」）が各所にある（[openRouterKey.ts:135](../web/src/services/openRouterKey.ts#L135)、[ApiKeyModal.tsx:69](../web/src/components/ApiKeyModal.tsx#L69)、[ApiKeyField.tsx:121](../web/src/components/ApiKeyField.tsx#L121)）。

### 2-6. ピッチの実態

`pitch` はブラウザ音声（`SpeechSynthesisUtterance.pitch`）にしか効いていない。OpenRouter 経由の TTS には `speed` しか送っておらず、**Fish Audio S2.1 Pro の API にもピッチのパラメータは無い**。→ 再生側で作る（D1）。

### 2-7. 声の上書きの保存形式

利用者が声を変えると [storage.ts:349](../web/src/services/storage.ts#L349) `saveFriendVoice` が **Voice 全体** を保存し、以後はプリセットより優先される。利用者がピッチを1回触ると、その後 `presetFriends.ts` の話者IDや調整値を直しても届かない。→ ピッチは別キー（D3）。

## 3. 決定事項

### 指示で確定

- **C1.** OpenRouter 1本化。LLM は `deepseek/deepseek-v4.1-flash` 固定、TTS は `fish-audio/s2.1-pro` 固定
- **C2.** 利用者が触れる声の調整は「声の高さ（ピッチ）」のみ
- **C3.** LLM モデルの変更は `#dev` の「テストモード」からのみ。TTS は開発者でも変更しない（TTS 検証モードは比較ツールとして残す）
- **C4.** 声の管理メニューは利用者に出さない。`#dev` に統合
- **C5.** 「OpenRouter 1本化と低コスト運用について」の案内枠は削除
- **C6.** テストは OpenRouter API キーを持つ人に限定
- **C7.** **Kokoro は不採用。Fish で使えない設定（ブラウザ音声、Qwen、Edge 音声名、モデル切替の退避、Kokoro ベースのカスタム声質）は取り除く**
- **C8.** 男性10人の Fish 話者IDは利用者が作成〜設定する（T-95）

### 推奨案で確定

| | 決定 |
| --- | --- |
| **D1** ピッチ | 再生速度で音程を変え、Fish に送る `speed` を `rate / pitch` にしてテンポを戻す。範囲 0.85〜1.20 |
| **D2** 無料モード | 画面からは無くし、キー必須の導線にする。Worker の無料代行コードは触らない（使われないだけ）。フロントの `freeMode.ts` は C7 と合わせて削除 |
| **D3** ピッチの保存 | `shabe_china_voice_pitch_<friendId>` に数値のみ。`saveFriendVoice`（Voice 全体）は開発者用 |
| **D4** カスタム友達の声 | 作成時に「同性のプリセット友達の声を借りる」。選んだ友達の Fish 話者ID・調整値・速度を複製 |
| **D5** 男性10人 | C8 のとおり利用者が作業。ツール（管理ダッシュボード）は `#dev` に残す |
| **D6** `#dev` の入口 | 現状のまま（合言葉なし） |
