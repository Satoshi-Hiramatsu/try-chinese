# しゃべチャイナ Web

しゃべチャイナのブラウザ版フロントエンドです。React 19、Vite、TypeScript strict、Tailwind CSS、PWAで構成されています。機能、セットアップ、画面説明の詳細は[ルートREADME](../README.md)を参照してください。

## 開発コマンド

リポジトリのルートで実行します。

```bash
npm run dev:web
npm run build:web
npm test
```

## 音声機能

- マイク入力は `MediaRecorder` で一発話を録音し、停止後に `/api/stt` へ1回だけ送って文字起こしします。ブラウザの認識イベントは送信内容に使用しません。
- HFモードでは一発話ずつ録音・文字起こし・送信し、相手の回答読み上げ後に次の録音を開始します。
- 音声入力中と音声回答後は入力欄へ自動フォーカスせず、Androidのソフトキーボードが意図せず開くことを防ぎます。
- 開発環境、または `?ttsDebug=1` 付きURLでは、設定からOpenRouter TTSモデル検証画面を開けます。

## PWA・レスポンシブ表示

- PWAのmanifestは `display: standalone` を使用します。通常のブラウザタブではアドレスバー等を確実に非表示にできません。
- 対応ブラウザではヘッダーの「その他」からFullscreen APIによる全画面表示を開始・終了できます。非対応環境では通常表示を維持します。
- スマートフォン横画面（`pointer: coarse` かつ高さ560px以下）では、最初の画面タップで全画面表示を1度だけ試み、ブラウザのアドレスバーを畳みます。拒否・非対応でも通常表示のまま利用できます。
- スマートフォン横画面では約4秒の無操作でアプリのヘッダーも畳み、その高さを立ち絵へ譲ります。画面タップで再表示され、「その他」メニューを開いている間は畳みません。
- スマートフォン横画面の立ち絵は画面の下端まで届き、テキスト枠と入力欄は右カラムへまとめます。入力欄の高さは実測して CSS 変数 `--vn-input-h` に渡し、テキスト枠が入力欄の下に潜り込まないようにします。
- タイトル・画面モード・HSKは常時表示し、低頻度操作は「その他」にまとめます。
- ノッチやホームインジケータには `viewport-fit=cover` とsafe-area insetで対応します。

## データと秘密情報

APIキー、会話履歴、設定、TTS検証履歴はブラウザ内に保存します。`.env*`、`.dev.vars`、APIキーなどの秘密情報はコミットしないでください。
